# Definition of Ready (DoR)

A task is "ready" to be picked up when:

- [ ] It has a GitHub issue using the Task template
- [ ] The goal is clear (what should work once it's done)
- [ ] It has acceptance criteria we can actually check
- [ ] It's small enough to finish in a day or two. If not, split it up
- [ ] We know which area it's in (frontend / backend / database / devops / docs)
- [ ] Anything it depends on is done, or at least we know about it
- [ ] Someone is assigned to it
- [ ] The team has talked about it at standup or planning so nobody is surprised
